# 🛒 Retrodenda - Backend API

Bienvenido al repositorio del backend de **Retrodenda**, una e-commerce dedicada a la moda y accesorios con estilo retro. Este proyecto utiliza `json-server` para proporcionar una API REST funcional de forma rápida y eficiente.

---

## 📋 Requisitos Previos

Antes de empezar, asegúrate de tener instalado:
* **Node.js** (versión 14 o superior).
* **npm** (viene incluido con Node.js).

---

## 🚀 Guía de Instalación Paso a Paso

Sigue estos pasos en tu terminal para levantar el proyecto:

### 1. Clonar el proyecto
Si has hecho un **fork**, clona tu propia versión:
```bash
git clone [https://github.com/TU_USUARIO/backend-tienda-retrodenda.git](https://github.com/TU_USUARIO/backend-tienda-retrodenda.git)
```


### 2. Entrar en la carpeta
cd backend-tienda-retrodenda


### 3. Instalar las dependencias
Este paso descargará json-server, que es la herramienta necesaria para que la API funcione.

npm install

### 4. Iniciar el servidor de desarrollo
Ejecuta el script configurado en el archivo package.json:

npm run dev


## 🛠️ Uso de la API
Una vez que el servidor esté corriendo, podrás acceder a los datos en la siguiente dirección:

📍 Endpoint principal: http://localhost:8000/productos

¿Qué datos encontrarás?
La base de datos contiene una lista de artículos organizados por:

Categorías: Bolsos, camisas, pantalones y zapatos.

Detalles: Nombre, precio, descripción, talla y stock disponible.


## 📁 Estructura del Proyecto
productos.json: Nuestra "base de datos" con toda la información de los productos.

package.json: Configuración del proyecto y scripts de arranque.

.gitignore: Archivo para evitar subir carpetas pesadas como node_modules.
